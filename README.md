# bank-complaints-analysis
3MTT Capstone Project-Nigerian Bank Customer Complaints Analysis
**Prepared by:** Florence Sydney

## Project Overview

This project analyzes customer complaint data across five Nigerian banks to identify complaint patterns, evaluate resolution performance, analyze resolution time, and generate actionable insights and recommendations.

The project was developed using Microsoft Excel, applying data cleaning, analysis, visualization, and dashboard development techniques.

## Data Disclaimer

The dataset used in this project is **synthetic data created for educational purposes**. It does not represent actual customer complaints or the official performance of the banks included in the analysis.

## What I Did

- Cleaned and standardized the dataset.
- Checked for duplicates and missing values.
- Standardized dates and categorical values.
- Created a Resolution Days field.
- Created PivotTables for data analysis.
- Analyzed complaints by bank, state, category, channel, status, priority, and customer satisfaction.
- Developed KPIs, charts, and interactive slicers.
- Created an interactive Excel dashboard.
- Generated key insights and recommendations from the analysis.

## Key Findings

- **1,256** customer complaints were recorded.
- **633** complaints were resolved.
- The average complaint resolution time was **7.0 days**.
- **Lagos** recorded the highest complaint volume with **476 complaints**.
- **Zenith Bank** recorded **250 complaints**.
- **Failed Transfer** was the highest complaint category for Zenith Bank, with **58 complaints**.

## Recommendations

- Improve failed transfer and fraud resolution.
- Strengthen mobile and USSD services.
- Follow up on unresolved complaints.
- Reduce complaint resolution delays.
- Increase support in areas with high complaint volumes.
